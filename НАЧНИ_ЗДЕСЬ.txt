НАЧНИ ЗДЕСЬ — навык Яндекс Алисы с Gemini

Это улучшенная версия шаблона. Главное отличие: исправлено хранение истории
(Яндекс разрешает только 1 КБ состояния), ответы очищаются для озвучки,
поиск срабатывает точнее, а у навыка есть приветствие, помощь и команда «пока».

ВАЖНО: Fork исходного шаблона не содержит улучшений из этой папки.
Загружайте именно эти файлы в свой новый репозиторий на GitHub.

1. Если скачали ZIP, распакуйте архив. ZIP целиком на GitHub не загружайте.
2. На GitHub нажмите + → New repository и создайте пустой репозиторий.
3. В нём выберите Add file → Upload files, перетащите содержимое папки проекта,
   а не саму папку или ZIP. Проверьте, что файл лежит по пути api/index.js.
   Не загружайте .env и ключи. Нажмите Commit changes.
4. Войдите на app.netlify.com, выберите Add new project → Import an existing
   project → GitHub и импортируйте именно этот репозиторий. Base directory
   оставьте пустой; конфигурация сборки уже в netlify.toml.
5. Нажмите Deploy и дождитесь завершения развёртывания.
6. В Netlify откройте Project configuration → Environment variables и добавьте:
   GEMINI_API_KEY — ключ Google AI Studio;
   SERPER_API_KEY — ключ Serper (необязательно, но включает поиск).
   Для переменных выберите Production.
7. После сохранения переменных запустите новое развёртывание через Deploys.
8. Скопируйте свой домен Netlify, добавьте /api
   и вставьте полный адрес в поле Webhook URL в настройках навыка Яндекс Диалогов.
9. В Яндекс Диалогах откройте раздел Тестирование и задайте вопрос навыку.

Всё работает в облаке Netlify: держать свой ПК включённым не нужно. Для истории
текущей сессии отдельное хранилище данных навыка не требуется.

КАК ПРОВЕРИТЬ БЕЗ ПРОГРАММИРОВАНИЯ

1. В настройках навыка выберите тип доступа Приватный и сделайте навык
   доступным для тестирования.
2. На колонке или в приложении с Алисой войдите в тот же аккаунт Яндекса,
   который используете для консоли разработчика.
3. Скажите: «Алиса, запусти навык [название или активационное имя навыка]».
4. Задайте вопрос и проверьте, отвечает ли Алиса.
5. Скажите «Пока» или «Хватит», чтобы проверить завершение диалога.

Если навык не запускается голосом или ещё не доступен для такого запуска,
откройте Яндекс Диалоги → ваш навык → Тестирование. Там можно проверить ответ
ещё до голосового запуска.

ЕСЛИ НАВЫК НЕ ОТВЕЧАЕТ

1. Проверьте Webhook URL: он должен заканчиваться на /api.
2. Проверьте переменные в Netlify и запустите новое развёртывание после изменения.
3. Откройте адрес вашего вебхука в браузере (GET /api). Он покажет, видит ли
   сервер ключи Gemini и Serper, не раскрывая сами ключи.
4. Не отправляйте API-ключи в чат и не загружайте их в GitHub.

ДОПОЛНИТЕЛЬНО

Если задать в Netlify переменную YANDEX_SKILL_ID, вебхук будет принимать запросы
только от вашего навыка. Это необязательно.

Node.js устанавливать не нужно: он нужен только для необязательных тестов
разработчика, а не для размещения или проверки навыка. Подробности — в README.md.
